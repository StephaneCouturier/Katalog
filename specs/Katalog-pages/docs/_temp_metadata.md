## Metadata Features

Katalog's intelligent metadata extraction helps you find and organize media files more effectively:

### What Metadata is Extracted
- **Images**: Dimensions, orientation, camera settings, creation date
- **Videos**: Duration, resolution, codec information, creation date  
- **Audio**: Artist, album, track info, duration, bitrate, creation date

### Extraction Levels
- **None**: No metadata extraction (fastest cataloging)
- **Media Basic**: Essential metadata for images, videos, and audio files
- **Media Extended**: Comprehensive metadata including technical details
- **Full Extended**: Maximum metadata extraction for all supported file types

### Smart Benefits
- **Search by Properties**: Find all photos over 2000px wide, videos longer than 5 minutes, or music by specific artists
- **Better Organization**: Automatically categorize files by type with enhanced accuracy
- **Rich Information**: See detailed file properties without opening the files
