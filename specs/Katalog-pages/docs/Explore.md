# Explore
## Summary
This page describes all the features of the **Explore** screen and how to use them.

The objective of this screen is to **explore the contents of a catalog of files** even when the physical device is not connected.

This view will load data after a right-click on a catalog from the **[Selection](Selection)** panel or the **[Catalogs](DevicesCatalogs)** list view, and chosing the context menu entry **Explore**.
![](/img/explore_01.png)

## Features
* Display the list of the directories and files of the selected catalog.
* Clicking on a file will try and open it if available
* A right click on a file will show the context menu as on the **[Search](Search)** screen to open the file or its directory, or copy information such as the file path.
* Folders can be listed with files, as well as sub-folders.
* If the order of the list is changed, the button *Order folders first* will list folders first, alphabetically, then the files alphabetically.
