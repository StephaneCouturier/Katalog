# Construire depuis les sources

## Résumé
Cette page fournit des conseils pour créer un catalogue à partir des sources.

Environnement de développement pour la version actuelle = **Qt uniquement**
* Disponible sur n'importe quelle plateforme (Linux, Windows, Apple)
* Installez Qt : https://www.qt.io/download
* Sélectionnez le kit Qt 6.6 et l'installation doit inclure l'IDE *QtCreator*.
* Katalog utilise le fichier .pro et qmake (pas cmake).
* A l'ouverture du fichier .pro, configurez le projet en sélectionnant le kit Qt 6.6.
* puis appuyez simplement sur *Exécuter* pour essayer de créer et d'exécuter le programme
