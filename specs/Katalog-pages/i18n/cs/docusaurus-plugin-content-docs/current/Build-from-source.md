# Sestavte ze zdroje

## Souhrn
Tato stránka poskytuje návod k sestavení Katalogu ze zdroje.

Vývojové prostředí pro aktuální verzi = **pouze Qt**
* Dostupné na jakékoli platformě (Linux, Windows, Apple)
* Nainstalujte Qt: https://www.qt.io/download
* Vyberte sadu Qt 6.6 a instalace by měla zahrnovat IDE *QtCreator*.
* Katalog používá soubor .pro a qmake (ne cmake).
* Při otevírání souboru .pro nakonfigurujte projekt výběrem sady Qt 6.6.
* poté stačí stisknout *Spustit* a pokusit se program sestavit a spustit
