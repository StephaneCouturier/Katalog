Hello all,

It has been 2 years since the first tests of QML, Kirigami, on Linux & Windows.<br/>
**Katalog 3.0 is close to be released!**<br/>
This is a call to anyone who would like to <b>contribute and help to improve the quality before official Release</b>.
Feel free to post feedback here, or directly as issues.<br/>


### ✨ What is Katalog 3

**Katalog 3** is the new major version of Katalog, transitionning to a more modern User Interface. It relies on QtQuick (instead of QtWidgets) and [Kirigami](https://develop.kde.org/frameworks/kirigami/) from KDE.

**Katalog 2** will be maintained for some time to address major bugs & light feature changes. Katalog 2.13 will be released at the same time as Katalog 3.0 to maintain full db compatiblity.

This is enabled by having done a full split of UI and backend. The common use of `/core` (backend) means that **Collections will remain compatible between both <u>latest</u> versions**.

Due to the heavy UI rework, some Katalog 3 elements are not quite matching Katalog 2 yet (especially Treeviews or Tables). This will be improve over time, given the user a choice between **Desktop classic** views (detailed tables) and "cleaner" / **Tablet/mobile** ready views.



### ✨ Before testing

1) ⚠️ BACKUP YOUR COLLECTION(S) FIRST 💾 !


2) CREATE A TEST COLLECTION IN KATALOG 2 BEFORE

3) First start:

When opening Katalog 3 <b>beta1</b> for the first time, it will <b>NOT</b> use the same settingsFile (.ini) and therefore it will <b>NOT</b> open your <b>last  Collection</b> nor personnal settings.<br/>
This is to protect even more your current collection and get feedback on a fresh start as well.<br/>


### ✨ What to test

1) **New UI** and global experience (starting from a blank Collection)

2) Conversion of a copy of a collection
Once in Katalog 3, open a COPY of your main collection. 
⚠️ Do not open files with Katalog 2.12 after using them in Katalog 3.0, some issues would appear.

3) Try out Katalog 2.13 beta1 on the same collection

4) Katalog 3 new features
