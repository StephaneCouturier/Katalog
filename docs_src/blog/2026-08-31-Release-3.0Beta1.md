Katalog 3.0 is almost ready to be released.<br>
This is a call to anyone who would like to <b>contribute and help to improve the quality before official Release</b>.<br>
Feel free to post feedback here, or directly as issues.


### ✨ What is Katalog 3

**Katalog 3** is the new major version of Katalog, transitionning to a more modern User Interface. It relies on QtQuick and Kirigami from KDE (instead of QtWidgets).

**Katalog 2** will be maintained for some time to address major bugs & light feature changes. Katalog 2.13 will be released at the same time as Katalog 3.0 to maintain full db compatiblity.

This is enabled by having done a full split of UI and backend. The common use of `/core` (backend) means that **Collections will remain compatible between both <u>latest</u> versions**.

Due to the heavy UI rework, some Katalog 3 elements are not quite matching Katalog 2 yet (especially Treeviews or Tables). This will be improve over time, given the user a choice between **Desktop classic** views (detailed tables) and "cleaner" / **Tablet/mobile** ready views.



### ✨ Before testing

1) ⚠️ BACKUP YOUR COLLECTION FIRST 💾 !


2) CREATE A TEST COLLECTION IN KATALOG 2 BEFORE


When opening Katalog 3 for the first time, it will use the same settingsFile (.ini) and therefore it will open your <b>last opened Collection</b>.<br/>
Katalog will run an update of the database to the latest db schema.<br/>

To avoid any trouble, simply save your collection and create a test one from Katalog 2 before.

This way Katalog 3.0 will start with a test dataset and not you actual collection.
