Hello all,

It has now been 2 years since the very first tests of QML, Kirigami, on Linux & Windows, confirming the feasibility and next big step for Katalog user experience.<br/>
**Katalog 3.0 release is near!**<br/>

This is a message to call to anyone who would like to <b>contribute and help to improve the quality before official Release</b>.
Feel free to post feedback here, or directly as issues.<br/>

---
### ✨ What is Katalog 3

**Katalog 3** is the new major version of Katalog, transitionning to a more modern User Interface. It relies on QtQuick (instead of QtWidgets) and [Kirigami](https://develop.kde.org/frameworks/kirigami) from KDE.

**Katalog 2** will be maintained for some time to address major bugs & light feature changes. Katalog 2.13 will be released at the same time as Katalog 3.0 to maintain full db compatiblity.

This is enabled by having done a full split of UI and backend. The common use of `/core` (backend) means that **Collections will remain compatible between both <u>latest</u> versions**.

---
### ✨ Before testing

1) ⚠️ BACKUP YOUR COLLECTION(S) FIRST 💾 !

2) CREATE A TEST COLLECTION IN KATALOG 2 BEFORE

3) Info: to make it even safer, when opening Katalog 3 <b>beta1</b> for the first time, it will <b>NOT</b> use the same settingsFile (.ini) and therefore it will <b>NOT</b> open your <b>last  Collection</b> nor personnal settings.<br/>
This is to protect even more your current collection and get your feedback on a fresh start as well.<br/>

4) Important for **macOS** users: this version has NOT been tested on a macOS and may not start at all (previous feedback received on version 3.alpha2). Please report if it starts or not, this would be very useful.


### ✨ What to test

- Note: **documentation updates are not available yet**

- **New UI** and global experience (starting from a blank Collection). Screenshots are very appreciated when describing an issue.

- Conversion of a copy of a collection (low risk but important to secure)
Once in Katalog 3, open a **COPY** of your main collection.<br/>
⚠️ Do not open files with Katalog 2.12 after using them in Katalog 2.13 or 3.0, some issues would appear.

- Try out Katalog 2.13 beta1 on the same collection

- Katalog 3 new features: see: [Katalog 3 changes](https://github.com/StephaneCouturier/Katalog/issues?q=is%3Aissue%20state%3Aopen%20milestone%3A3.0) (it is not quite exhaustive but already a good list)
