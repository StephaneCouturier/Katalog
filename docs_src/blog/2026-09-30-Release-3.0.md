Hello all,

It has now been 2 years since the very first tests of QML, Kirigami, on Linux & Windows, confirming the feasibility and next big step for Katalog user experience.<br/>
**Katalog 3.0 is now Released!**<br/>


### ✨ Katalog 3 introduction

* **Katalog 3** marks the transition to a more modern User Interface. It relies on QtQuick (instead of QtWidgets) and [Kirigami](https://develop.kde.org/frameworks/kirigami) from KDE.

* <b>All features available in Katalog 2.12</b> have been ported in Katalog 3 with many improvements.

* **Katalog 2** has been maintained (bugs & light feature changes) to version 2.13, keeping full db compatiblity with Katalog 3.0. 

* Older versions of Katalog (2.12 and before) should not be used on collections opened with 2.13 or 3.0.

### ✨ Katalog 3 Main improvements:


- **#766** SEARCH: Regular expression support for file name search
- **#222 SEARCH: Search History / Clear list (can keep last 10 searches)**

<!-- truncate --> 

- **#401 DEVICES: breakdown a catalog onto 1 per file type or 1 by sub folder**
    Split Catalog per sub directory
    Split Catalog per File type
    See:[DevicesCatalogs#catalog-context-menu](https://stephanecouturier.github.io/Katalog/docs/DevicesCatalogs#catalog-context-menu)

- **#770 DEVICES: replace Storage root path in devices and indexes**
    When a Storage device's mount point or drive letter changes, every indexed file/folder path become obsolete.
    The current fallback is a full re-scan. this feature offers a fast, offline alternative that performs a prefix-replace, without requiring the device to be mounted.


### ⚠️ Technical changes:
- As for any new version, it is highly recommended to **backup the collections** 💾, and test the new version on other copies.
- **Database updates**: added fields to support collections import and image folder

### 📦 Distribution Formats:
- As usual, **Window 64**, **Linux**, **macOS**
- **Linux**: for easy Linux installation, use [**Flathub/Flatpak**](https://flathub.org/en/apps/io.github.stephanecouturier.Katalog)
