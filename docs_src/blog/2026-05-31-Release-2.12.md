✨ Katalog 2 Main improvements:

- **#766 SEARCH: Regular expression support for file name search**
- **#222 SEARCH: Search History / Clear list (can keep last 10 searches)**
- **#684 SEARCH: List as Search input (several text search input)**
    Pasting a list of term (several lines) and run the search, the results is equivalent to running individual searches with sames criteria except on each different term (a term can be several words).
    See:[Development-Roadmap#katalog-3](https://stephanecouturier.github.io/Katalog/docs/Search#file-name)
    
<!-- truncate --> 

- **#401 DEVICES: breakdown a catalog onto 1 per file type or 1 by sub folder**
    Split Catalog per sub directory
    Split Catalog per File type
    See:[Development-Roadmap#katalog-3](https://stephanecouturier.github.io/Katalog/docs/DevicesCatalogs#catalog-context-menu)

- **#770 DEVICES: replace Storage root path in devices and indexes**
    When a Storage device's mount point or drive letter changes, every indexed file/folder path become obsolete.
    The current fallback is a full re-scan. this feature offers a fast, offline alternative that performs a prefix-replace, without requiring the device to be mounted.

- **#776 APP: File database mode as default instead of Memory mode**

- **#775 CREATE: replace the Select Storage list by a device tree**

    
✨ Katalog 3 Preparation:
- **#747 Katalog 3 Alpha 2: Full featured app for testing and feedback**  
  	Katalog 3 is now covering all features of Katalog 2 except mutli-languages.  
  	See:[Development-Roadmap#katalog-3](https://stephanecouturier.github.io/Katalog/docs/Development-Roadmap#katalog-3)
    Versions: Linux AppImage only, Windows Portable only, macOS.

⚠️ Technical changes:
- As for any new version, it is highly recommended to **backup the collections** 💾, and test the new version on other copies.
- **Database updates**: added fields to support collections import and image folder

📦 Distribution Formats:
- As usual, **Window 64**, **Linux**, **macOS**
- **Linux**: for easier Linux deployment, now available on [**Flathub/Flatpak**](https://flathub.org/en/apps/io.github.stephanecouturier.Katalog)
