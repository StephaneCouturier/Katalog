Aperçu général

Indexation de fichiers & Gestionnaire de périphériques de stockage​

Katalog est un puissant gestionnaire de catalogue de fichiers qui vous aide à organiser et à retrouver vos fichiers.
Il donne une vue complète des fichiers présents sur plusieurs périphériques de stockage sans avoir besoin de les connecter.
Katalog crée des index complets pour que vous puissiez rechercher dans toute votre collection de fichiers depuis un seul endroit, que vous gériez des disques internes et externes, des clés USB, des stockages réseau ou des disques optiques (Blu-ray, DVD, CD).

  • Cataloguez tout : Créez des index détaillés des fichiers de n'importe quel périphérique de stockage
  • Recherchez hors ligne : Trouvez des fichiers instantanément sans connecter ou monter le périphérique d'origine
  • Organisez votre collection : Gérez plusieurs périphériques de stockage et leurs catalogues dans une hiérarchie unifiée

8 onglets principaux pour 8 fonctionnalités principales

  1. Créer des catalogues de fichiers
  2. Rechercher des fichiers sur plusieurs périphériques de stockage sans avoir besoin de les connecter
  3. Explorer la hiérarchie des catalogues et les fichiers
  4. Organiser les Périphériques de stockage et leurs catalogues dans une hiérarchie unifiée avec des périphériques virtuels
  5. Obtenir des Statistiques sur vos collections de fichiers et l'utilisation du stockage
  6. Personnaliser les Étiquettes et les attribuer aux répertoires pour des recherches ou statistiques supplémentaires
  7. Comparer les catalogues de Sauvegarde pour confirmer la couverture des fichiers et dossiers sauvegardés entre les périphériques source et cible
  8. Personnaliser votre expérience avec vos Paramètres tels que la langue et le thème

Fonctionnalités principales​

Informations détaillées sur les fichiers​

  • Intelligence du type de fichier : Détection standard par extension et vérification du type MIME
  • Options de catalogue : Inclure uniquement un type de fichiers, et inclure/exclure les répertoires ou fichiers cachés
  • Extraction de métadonnées : Extraction automatique des métadonnées des images (dimensions, informations de l'appareil photo), vidéos (durée, résolution) et fichiers audio (artiste, album, durée) ou tout autre type de fichier.
  • Système d'étiquettes de dossier : Organisez et catégorisez les dossiers avec des étiquettes personnalisées

Recherche et découverte puissantes​

  • Paramètres de recherche avancés : Trouvez des fichiers par nom, chemin, taille, date, type de fichier et métadonnées
  • Filtrage intelligent : Utilisez plusieurs critères simultanément pour affiner rapidement les résultats
  • Trouver les doublons : Identifiez les fichiers en double sur différents périphériques de stockage
  • Trouver les différences : Visualisez les différences entre deux emplacements de stockage ou versions de sauvegarde

Gestion des périphériques et catalogues​

  • Organisation des périphériques : Organisez les périphériques de stockage dans une structure hiérarchique (Virtuel > Stockage > Catalogues)
  • Mise à jour : Maintenez les catalogues à jour avec des mises à jour manuelles ou automatiques
  • Support d'importation : Importez des catalogues d'autres outils comme VVV

Analyse et gestion​

  • Explorateur de fichiers : Parcourez le contenu des catalogues comme si le périphérique était connecté
  • Statistiques : Suivez vos collections de fichiers et l'utilisation du stockage
  • Gestion des sauvegardes : Cartographiez et comparez les répertoires sources avec leurs sauvegardes
  • Opérations par lots : Exportez les résultats et effectuez des actions par lots sur les fichiers

Capacités avancées​

  • Interface en ligne de commande : Automatisez les mises à jour de catalogues et les recherches via la ligne de commande (Linux)
  • Flexibilité de la base de données : Choisissez entre le stockage en fichiers CSV ou base de données SQLite
