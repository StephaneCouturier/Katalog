Créer

Résumé​

Cette page décrit la page Créer, où un nouveau catalogue est créé : un index des fichiers d'un dossier, conservé dans la collection pour pouvoir être recherché et exploré même lorsque le périphérique est déconnecté.

Cela se fait en trois étapes :

  1. Définir le catalogue : le dossier à indexer, son périphérique de stockage et son nom.
  2. Choisir les options de contenu : types de fichiers, sous-dossiers, fichiers cachés, métadonnées, sommes de contrôle et exclusions.
  3. Cliquer sur Créer.

Définition du catalogue​

ChampDescription
Chemin sourceLe dossier à indexer. Il est rempli avec le chemin du périphérique sélectionné sur la page Sélection, et peut être saisi ou choisi avec Sélectionner le chemin.
StockageLe périphérique de stockage où se trouve le dossier : le disque ou l'ordinateur (voir Périphériques). Seuls les périphériques de stockage sont listés. Une nouvelle collection en a déjà un, Disque local. Pour en ajouter un autre, utilisez Ajouter un Stockage sur la page Périphériques.
Nom du catalogueLe nom du nouveau catalogue. Chaque catalogue doit avoir son propre nom. Générer le nom à partir du chemin (le bouton à côté du champ) en crée un à partir du chemin source, avec _ à la place de / et :.

Lorsqu'un champ manque ou est incorrect, un message en haut de la page indique ce qui est nécessaire, par exemple Indiquez un nom pour ce nouveau catalogue. Il disparaît lorsque le champ est corrigé. Il en va de même lorsque le dossier source n'existe pas, ou lorsqu'un autre catalogue porte déjà ce nom.

Lorsque le dossier source ne contient aucun fichier, une question est d'abord posée : le dossier est peut-être vide, ou le périphérique n'est peut-être pas monté à cet endroit. Oui crée tout de même le catalogue, vide.

Options de contenu​

Les options déterminent ce qui est indexé. Elles peuvent être modifiées plus tard en modifiant le catalogue (voir Modifier un périphérique) ; le catalogue doit alors être mis à jour pour en tenir compte.

Type de fichier​

Le catalogue peut être limité à un type de fichiers.

TypeDescriptionDéfinitionExemples d'extensions
TousTous les types de fichiers, sans filtrage.
AudioMusique, podcasts, enregistrements audio et fichiers sonores.Selon la définition des types MIME.MP3, FLAC, AAC, M4A, OGG, WAV, AIFF, Opus, WMA, MIDI, AMR (plus de 50 formats)
ImagePhotos, graphiques, diagrammes, icônes et contenus visuels.Selon la définition des types MIME.JPG, PNG, HEIC, WebP, TIFF, RAW, SVG, XCF, GIF, BMP (plus de 100 formats)
TexteDocuments, fichiers de code, balisage, fichiers de données et contenus lisibles.Définition propre à Katalog : tous les fichiers dont le type MIME commence par text/, plus des fichiers d'application comme les documents PDF et Word.PDF, DOCX, ODT, Markdown, HTML, JSON, fichiers de code source, livres numériques (plus de 100 formats)
VidéoFilms, clips, animations et contenus vidéo.Selon la définition des types MIME.MP4, MKV, AVI, WebM, MOV, FLV, 3GP, OGV, M2TS (plus de 40 formats)
AutreTous les autres types de fichiers.Définition propre à Katalog.ZIP, RAR, EXE, DLL, ISO : exécutables, archives, fichiers système et fichiers d'application non classés comme Texte.
AucunFichiers dont le type ne peut pas être déterminé à partir de l'extension.Fichiers sans extension ou avec une extension inconnue.

Le type d'un fichier est déterminé à partir de son extension, à l'aide de la base de données MIME du système : des centaines de formats sont reconnus, et de nouveaux au fil des mises à jour du système. Cela permet une indexation rapide. Un fichier dont l'extension est erronée ou absente peut donc recevoir un mauvais type.

Inclure les sous-dossiers​

Coché (par défaut), les fichiers de tous les sous-dossiers sont indexés. Décoché, uniquement les fichiers situés directement dans le chemin source.

Inclure les fichiers cachés​

Aucun (par défaut) ignore les fichiers et dossiers cachés ; Tous les inclut.
Sur un dossier personnel ou un disque système, les dossiers cachés (.cache, .local…) peuvent contenir beaucoup de fichiers : exclure ceux qui ne sont pas utiles permet de garder un catalogue léger.

Inclure les métadonnées​

La quantité d'informations lue dans le contenu des fichiers. Cela allonge l'indexation, mais donne des résultats plus riches dans la Recherche (dimensions, durée, artiste…) et dans les Statistiques.

NiveauCe qui est lu
AucunAucune métadonnée : le plus rapide.
Média basiqueL'essentiel des images, vidéos et fichiers audio : dimensions et orientation des images ; dimensions, durée, codec et fréquence d'images des vidéos ; artiste, album, piste, durée et débit des fichiers audio.
Média étenduToutes les métadonnées des images, vidéos et fichiers audio, y compris les détails techniques.
Complet étenduToutes les métadonnées de chaque type de fichier pris en charge.

Les niveaux étendus utilisent la bibliothèque KFileMetaData, qui détermine les types et champs pris en charge ; leurs métadonnées peuvent être consultées avec Afficher les métadonnées étendues (JSON) dans les résultats de recherche et dans Explorer.
Les niveaux Média ne lisent que les fichiers multimédias : les autres fichiers sont ignorés. Les fichiers endommagés ou illisibles sont ignorés sans interrompre le catalogue.

Fichiers multimédias pris en charge :

  • Images : jpg, png, gif, bmp, tiff, webp, svg, heic, raw, xcf
  • Vidéos : mp4, mkv, avi, mov, wmv, flv, webm, m4v, mpg, 3gp, ogv, vob
  • Audio : mp3, wav, flac, ogg, m4a, aac, wma, opus, aiff, mid, amr

Inclure la somme de contrôle​

SHA-256 calcule une somme de contrôle pour chaque fichier : une empreinte de son contenu. Les sommes de contrôle rendent exactes les recherches de doublons et de différences, et permettent de vérifier plus tard que les fichiers n'ont pas changé.
⚠️ C'est beaucoup plus long que les autres options, car toutes les données de chaque fichier sont lues (voir le Guide de performance).

Exclure les dossiers ou fichiers​

Chemins ou noms qui ne sont pas indexés dans ce catalogue.
Saisissez un chemin ou un nom dans Chemin ou nom à exclure, ou choisissez un dossier avec Sélectionner le chemin, puis cliquez sur Ajouter. Le bouton Supprimer à côté d'une entrée la retire de la liste.
La liste est enregistrée avec le catalogue.

Paramètres globaux​

La section Paramètres globaux contient les paramètres partagés par tous les catalogues de la collection. Le bouton sur sa ligne de titre la replie ou la déplie.

Exclusions globales de dossiers​

Chemins exclus de chaque catalogue, lors de sa création et à chacune de ses mises à jour.
Saisissez un chemin dans Chemin à exclure globalement (ou utilisez Sélectionner le chemin), puis cliquez sur Ajouter. Supprimer à côté d'une entrée la retire.

Fonctionnement des exclusions​

Les exclusions globales et celles du catalogue s'additionnent : un fichier ou un dossier écarté par l'une ou l'autre liste n'est pas indexé.
Une exclusion est une correspondance de texte : tout fichier ou dossier dont le chemin complet contient le texte est ignoré. La correspondance est sensible à la casse.

  • Chemin complet : /home/username/Downloads/temp ignore ce dossier et tout son contenu.
  • Nom de dossier : node_modules ignore tous les dossiers node_modules, où qu'ils soient.
  • Partie d'un nom : .cache ignore /home/username/.cache/, mais aussi /home/username/.cachedata/, puisque les deux chemins contiennent le texte.

Création du catalogue​

Créer enregistre le catalogue et lance l'indexation. La progression est affichée dans le panneau d'activité en bas de la fenêtre (voir Interface). Si une autre opération est en cours, la création attend dans la file d'attente.

L'indexation se déroule en deux phases :

  1. la liste des fichiers est lue et enregistrée : le catalogue est utilisable dès la fin de cette phase,
  2. ensuite, si elles ont été choisies, les métadonnées et les sommes de contrôle sont lues.

Stop met fin à la création :

  • pendant la première phase, le catalogue n'est pas créé,
  • pendant la seconde phase, le catalogue est conservé avec sa liste complète de fichiers ; les métadonnées ou sommes de contrôle pas encore lues sont complétées à la prochaine mise à jour du catalogue.

À la fin de la création, le nouveau catalogue est sélectionné sur la page Sélection et la page Périphériques s'ouvre avec un rapport : le nom et le chemin du catalogue, son nombre de fichiers et sa taille totale, et, lorsque son stockage a été mis à jour, l'espace utilisé, libre et total du stockage avec ce qui a été ajouté. Si une analyse des métadonnées ou des sommes de contrôle n'est pas terminée, un message l'explique à la place.
Fermer (ou Échap) ferme la page.

10Dossiers exclus⚫ FaibleRéduit le nombre effectif de fichiersnode_modules, .cache et les dossiers temporaires peuvent représenter 20–30 % des fichiers d'un dossier personnel.
