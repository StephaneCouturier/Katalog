Périphériques

Résumé​

Cette page décrit la page Périphériques, où les périphériques de la collection sont listés et gérés :

  • le modèle des périphériques : catalogues, stockages, périphériques virtuels et groupes,
  • les vues : tous les périphériques, stockages ou catalogues, en cartes ou en tableau,
  • les actions de la page : mettre à jour tous les catalogues actifs, instantané, nouveau groupe ou stockage,
  • le menu contextuel d'un périphérique : actualiser, explorer, éditer, sommes de contrôle, diviser, attribuer, supprimer.

La modification d'un périphérique (nom, chemin, options du catalogue, détails du stockage) est décrite sur la page Modifier un périphérique.

Modèle des périphériques​

Définitions​

  • Un Catalogue est un index des fichiers d'un répertoire : son chemin source. Les catalogues se créent sur la page Créer.
  • Un périphérique de Stockage est un disque ou un autre support physique où des fichiers sont stockés. Il a un chemin où il est monté, et un espace physique.
  • Un périphérique Virtuel regroupe d'autres périphériques. Il n'a pas de données propres, et additionne les chiffres des périphériques situés en dessous de lui.
  • Un Groupe est un périphérique virtuel situé en haut de l'arborescence :
    • le Groupe physique est unique et réservé aux périphériques physiques (ordinateur, disque, téléphone…) et à leurs catalogues,
    • tout autre groupe est un Groupe virtuel, auquel des catalogues existants sont attribués, par exemple tous les catalogues de photos dans un groupe Photos.

Tout périphérique peut avoir un commentaire : une note libre, affichée à côté de son nom.

Hiérarchie​

Un catalogue appartient à un stockage, dans le Groupe physique. Il peut aussi être attribué à des périphériques virtuels des Groupes virtuels : cela permet de chercher uniquement dans ces catalogues, et de voir leurs totaux.

Périphériques disponibles​

Un périphérique est disponible lorsque son chemin est accessible : le disque est connecté et monté. Son icône est affichée en couleur ; un périphérique non disponible a une icône grise.
Les catalogues des périphériques non disponibles peuvent toujours être recherchés et explorés ; seules les actions qui lisent le disque (actualiser, ouvrir, sommes de contrôle…) ont besoin du périphérique.

Vues​

La barre en haut de la page choisit ce qui est listé et comment.

BoutonEffet
Tous les périphériquesToute l'arborescence : le Groupe physique avec ses stockages et catalogues, et les Groupes virtuels avec leurs périphériques attribués.
StockageUniquement les périphériques de stockage.
CataloguesUniquement les catalogues.
CartesChaque périphérique est une carte, avec son nom, son commentaire, ses chiffres et un menu d'actions.
TableauChaque périphérique est une ligne, avec une colonne par valeur.
Tableau completDans le tableau, affiche toutes les colonnes, y compris les identifiants internes et les détails moins utilisés.
Filtrer depuis la sélectionListe uniquement le périphérique sélectionné sur la page Sélection et les périphériques situés en dessous de lui.

Les choix sont conservés pour chaque collection.

Totaux​

Avec Stockage ou Catalogues, une barre sous les boutons donne les totaux des périphériques listés :

  • Catalogues : nombre de catalogues, Taille Totale des Fichiers, Nombre Total de Fichiers,
  • Stockage : nombre de périphériques, Espace Total, espace Utilisé et Libre.

Cartes​

Une carte montre l'icône et le nom du périphérique, son commentaire, et une ligne avec son type, son nombre de fichiers et sa taille, l'espace utilisé, libre et total pour un stockage, et la date de sa dernière mise à jour.
Dans Tous les périphériques, les cartes sont en retrait pour montrer l'arborescence, et la flèche à droite d'une carte replie ou déplie les périphériques situés en dessous.
Le bouton de menu à droite d'une carte, un clic droit ou un appui long ouvre le menu contextuel.

Tableau​

  • Cliquez sur le titre d'une colonne pour trier selon cette colonne ; cliquez à nouveau pour inverser l'ordre. Les nombres, tailles et dates sont triés selon leur valeur.
  • Faites glisser la ligne entre deux titres de colonnes pour changer la largeur d'une colonne ; double-cliquez dessus pour ajuster la colonne à son contenu. Les largeurs de Nom et Chemin sont conservées, séparément pour chaque vue.
  • Dans Tous les périphériques, la flèche devant un nom replie ou déplie les périphériques situés en dessous.
  • Faites un clic droit sur une ligne (ou un appui long) pour ouvrir le même menu contextuel que sur une carte.
  • Le clavier fonctionne comme dans les résultats de recherche. Dans Tous les périphériques, ← et → replient et déplient aussi la ligne sélectionnée.

Colonnes principales :

VueColonnes
Tous les périphériquesNom, Nombre de fichiers, Taille Totale, Espace utilisé, Espace libre, Espace total, Date de mise à jour, Chemin.
StockageNom, ID de stockage, Nombre de fichiers, Taille Totale, Espace utilisé, Espace libre, Espace total, Date de mise à jour, Chemin, Étiquette, Système de fichiers.
CataloguesNom, Nombre de fichiers, Taille Totale, Date de mise à jour, Chemin, Type de Fichier, Caché, Métadonnées, Somme de contrôle, Stockage parent.

Tableau complet ajoute, selon la vue : Type de périphérique, Actif, les identifiants, Type, Marque, Modèle, Numéro de Série, Date de Fabrication, Commentaire 1 à Commentaire 3, Version de l'application, et en mode Mémoire Date de chargement et Chemin du fichier.

Actions de la page​

ActionDescription
Tous les actifsMet à jour tous les catalogues disponibles situés sous le périphérique sélectionné sur la page Sélection (toute la collection lorsque Tous est sélectionné). Une question propose d'abord d'afficher un résumé pour chaque catalogue (Oui), uniquement le résultat global (Non), ou d'annuler.
StopArrête la mise à jour en cours.
InstantanéEnregistre les chiffres actuels de toute la collection (fichiers et taille des catalogues, espace libre et total des stockages), pour les Statistiques. Un résumé montre les nouveaux totaux et ce qui a changé depuis l'instantané précédent.
Insérer un groupe virtuelCrée un nouveau Groupe virtuel et l'ouvre dans Modifier un périphérique.
Ajouter un StockageCrée un nouveau périphérique de stockage dans le Groupe physique et l'ouvre dans Modifier un périphérique.
FermerFerme la page (également Échap).

Les mises à jour demandées pendant qu'une autre est en cours ne sont pas perdues : elles attendent dans une file d'attente, affichée dans le panneau d'activité (voir Interface).

Diviser un catalogue​

Un catalogue peut être remplacé par plusieurs catalogues plus petits. Le catalogue d'origine est supprimé : cette opération ne peut pas être annulée.

  • Diviser le catalogue par sous-répertoire : crée un catalogue pour chaque sous-répertoire situé directement sous le chemin source, nommé <nom du catalogue>_<sous-répertoire>, et un catalogue nommé <nom du catalogue>_(root) pour les fichiers situés directement dans le chemin source. Une confirmation est d'abord demandée.
  • Diviser le catalogue par type de fichier : crée un catalogue par type de fichier trouvé (Audio, Image, Texte, Vidéo, Autre), sur le même chemin source. La boîte de dialogue propose :
    • Vérifier puis diviser : lance d'abord Vérifier les types MIME, pour un résultat exact, puis divise. Disponible lorsque le périphérique est disponible.
    • Diviser sans vérifier : utilise les types de fichiers déjà enregistrés dans le catalogue.
