Sélection

Résumé​

Cette page décrit la page Sélection : la liste de tous les périphériques de la collection, présentée sous forme d'arborescence de cartes. C'est la première page de la fenêtre, et les autres écrans s'ouvrent à côté d'elle (voir Interface).

Sélectionner un périphérique définit la portée des autres écrans :

  • Recherche : la recherche porte sur les fichiers du périphérique sélectionné,
  • Périphériques : avec Filtrer depuis la sélection, seuls le périphérique sélectionné et ses sous-périphériques sont listés,
  • Créer : le stockage sélectionné est proposé pour le nouveau catalogue,
  • Sauvegarde : les liens de sauvegarde sont filtrés sur le périphérique sélectionné,
  • Statistiques : les graphiques montrent le périphérique sélectionné.

Périphérique sélectionné​

Le haut de la page montre toujours le périphérique sélectionné, avec son icône et son nom. Lorsqu'aucun périphérique n'est sélectionné, il affiche Tous : la collection entière.

Cliquer dessus fait défiler la liste jusqu'à la carte sélectionnée, ce qui est pratique dans une longue liste. Cela ne change pas la sélection.

Cartes des périphériques​

Chaque périphérique de la collection est présenté sous forme de carte, en retrait sous son périphérique parent.

  • Cliquez sur une carte pour sélectionner le périphérique. La carte sélectionnée est mise en évidence.
  • Faites un clic droit sur une carte (ou un appui long sur un écran tactile) pour ouvrir son menu contextuel.
  • La flèche à droite d'une carte masque ou affiche ses sous-périphériques.

Le type de périphérique se reconnaît à son icône et au style de son nom :

PériphériqueIcôneNom
Périphérique ou groupe Virtuelplusieurs disquesgras italique, atténué
Périphérique de Stockagedisque durgras, légèrement atténué
Cataloguedisque optique (une icône lorsque le catalogue est disponible, une autre lorsqu'il ne l'est pas)normal

Voir Périphériques pour savoir ce que sont les périphériques Virtuel, Stockage et Catalogue.

Lorsque les infos des périphériques sont affichées, une seconde ligne sous le nom indique :

  • pour un Catalogue : son nombre de fichiers et leur taille totale,
  • pour un périphérique de Stockage ou Virtuel : le nombre de fichiers et la taille totale de ses catalogues, puis l'espace utilisé.

Filtre et boutons de l'arborescence​

Au-dessus des cartes :

ContrôleUtilisation
Champ Nom...Filtre les cartes par nom de périphérique : seuls les périphériques dont le nom contient le texte saisi sont listés, sans tenir compte de la casse. Il filtre les périphériques, pas les fichiers. Le bouton en forme de croix l'efface. Ctrl+F place le curseur dans ce champ.
Afficher les infos du périphériqueAffiche ou masque la seconde ligne des cartes.
Réduire d'un niveauMasque le niveau de périphériques le plus profond actuellement affiché.
Développer d'un niveauAffiche un niveau de périphériques supplémentaire.

Menu contextuel​

Le menu contextuel commence par le nom du périphérique, suivi de :

ÉlémentAffiché pourAction
Cherchertous les périphériquesSélectionne le périphérique et ouvre la page Recherche.
Actualiserles périphériques Virtuels et de Stockage, et les Catalogues disponiblesMet à jour le périphérique : analyse à nouveau les fichiers de ses catalogues. Demandé pendant qu'une autre opération est en cours, il est ajouté à la file d'attente.
Explorerles CataloguesSélectionne le catalogue et l'ouvre dans la page Explorer.
Ouvrir le dossiertous les périphériquesOuvre le dossier du périphérique dans le gestionnaire de fichiers.
Modifiertous les périphériquesOuvre la page de modification du périphérique (voir Périphériques).

Chercher et Explorer sélectionnent d'abord le périphérique, de sorte que la carte mise en évidence correspond toujours à ce qui est recherché ou exploré. Actualiser, Ouvrir le dossier et Modifier agissent sur le périphérique cliqué sans changer la sélection.

Rechercher dans un lecteur connecté​

La recherche directe dans un dossier d'un lecteur connecté, sans catalogue, se choisit sur la page Recherche elle-même (Lecteur connecté), pas dans la Sélection.
