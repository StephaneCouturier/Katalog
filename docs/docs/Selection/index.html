Selection

Summary​

This page describes the Selection page: the list of all devices of the collection, shown as a tree of cards. It is the first page of the window, and the other screens open next to it (see Interface).

Selecting a device sets the scope of the other screens:

  • Search: the search runs in the files of the selected device,
  • Devices: with Filter from Selection, only the selected device and its sub-devices are listed,
  • Create: the selected storage is proposed for the new catalog,
  • Backup: the backup links are filtered on the selected device,
  • Statistics: the charts show the selected device.

Selected device​

The top of the page always shows the selected device, with its icon and name. When no device is selected, it shows All: the whole collection.

Clicking it scrolls the list to the selected card, which is useful in a long list. It does not change the selection.

Device cards​

Each device of the collection is shown as a card, indented under its parent device.

  • Click a card to select the device. The selected card is highlighted.
  • Right-click a card (or press and hold on a touch screen) to open its context menu.
  • The arrow on the right of a card hides or shows its sub-devices.

The type of device is shown by its icon and its name style:

DeviceIconName
Virtual device or groupseveral drivesbold italic, dimmed
Storage devicehard drivebold, slightly dimmed
Catalogdisc (one disc icon when the catalog is available, another when it is not)normal

See Devices for what Virtual, Storage and Catalog devices are.

When the device info is shown, a second line under the name gives:

  • for a Catalog: its number of files and their total size,
  • for a Storage or Virtual device: the number of files and total size of its catalogs, then the used space.

Filter and tree buttons​

Above the cards:

ControlUse
Name... fieldFilters the cards by device name: only the devices whose name contains the typed text are listed, whatever the case. It filters devices, not files. The cross button clears it. Ctrl+F puts the cursor in this field.
Show device infoShows or hides the second line of the cards.
Collapse one levelHides the deepest level of devices currently shown.
Expand one levelShows one more level of devices.

Context menu​

The context menu starts with the name of the device, followed by:

ItemShown forAction
Searchall devicesSelects the device and opens the Search page.
UpdateVirtual and Storage devices, and available CatalogsUpdates the device: scans the files of its catalogs again. Requested while another operation is running, it is added to the queue.
ExploreCatalogsSelects the catalog and opens it in the Explore page.
Open folderall devicesOpens the folder of the device in the file manager.
Editall devicesOpens the device edit page (see Devices).

Search and Explore select the device first, so the highlighted card always matches what is searched or explored. Update, Open folder and Edit act on the right-clicked device without changing the selection.

Search in a connected drive​

Searching directly in a folder of a connected drive, without a catalog, is chosen on the Search page itself (Connected drive), not in the Selection.
