Overview

Files indexing & Storage devices manager​

Katalog is a file catalog manager that helps you organize and find files.
It gives a full view of the files across multiple storage devices without needing them connected.
Katalog creates indexes so you can search your entire file collection from one place, whether you manage internal and external drives, USB sticks, network storage, or discs (Blu-ray, DVD, CD).

  • Catalog everything: create detailed indexes of the files of any storage device.
  • Search offline: find files without connecting or mounting the original device.
  • Organize the collection: manage storage devices and their catalogs in one hierarchy.
  • Back up: copy or move the files missing from a backup, using the catalogs.

Pages​

The window shows the Selection page on the left: the tree of all the devices of the collection. Selecting a device sets the scope of the other pages. Each feature opens as a page next to it, from the drawer (see Interface):

  1. Search files across all the storage devices, without needing them connected, and act on the results.
  2. Organize the Devices and their catalogs in one hierarchy, with virtual devices to group them, and edit them.
  3. Explore the folders and files of a catalog.
  4. Create catalogs of files.
  5. Copy or move files with Backup links, and check the coverage of the backups.
  6. Follow the growth of the collection in Statistics.
  7. Assign Tags to folders, for extra search possibilities.
  8. Set up the collection and the application in the Settings: data mode, import, theme, language.

Key features​

Rich file information​

  • File type detection: the type of each file is found from its extension, for hundreds of formats.
  • Catalog options: include only a type of files, sub-folders or not, hidden files, and exclude folders or files.
  • Metadata extraction: dimensions of images and videos, duration of videos and audio files, artist and album of music, or any metadata of other file types.
  • File checksum: SHA-256 checksums for exact duplicate and difference searches, and to verify files.
  • Folder tags: organize and categorize folders with your own tags.

Search & discovery​

  • Search criteria: find files by name (several texts, exclusions, regular expressions), folder, size, date, file type and metadata.
  • Find duplicates: identify duplicate files across devices.
  • Find differences: see the differences between two devices, for example a folder and its backup.
  • Actions on results: filter the results, export them, verify checksums, extract metadata, move to trash.

Devices & catalogs​

  • Device hierarchy: physical group, storage devices and catalogs, and virtual groups.
  • Update: keep the catalogs current, one by one or all the available ones at once.
  • Path changes: when a drive is mounted somewhere else, fix all its catalogs in seconds, without reading the drive.
  • Collection import & update: import devices from another Katalog collection or from VVV, and refresh them later.

Analysis & management​

  • File explorer: browse the content of a catalog as if the device were connected, with the size of each folder.
  • Statistics: track the growth of the collection and of the storage space.
  • Backup & archive: copy or move files between catalogs, preview, run several links at once, and check the coverage.
  • Data modes: keep the collection in a folder of files, in a SQLite database, or in a hosted database.

macOS Compatibility​

  • Minimum macOS version: macOS 15 (Sequoia) or later
  • Tested on: macOS 15 (Sequoia), Apple Silicon
  • Architecture: Apple Silicon (M1/M2/M3) only. Intel Macs are not supported — Rosetta 2 translates Intel software to run on Apple Silicon, not the other way round, so there is no way to run this build on an Intel Mac.
  • Build environment: Built on macOS 15 (Sequoia) with Qt 6 and KDE Frameworks 6 (KF6), via Homebrew

Important: the app is not code-signed or notarized.

macOS will block the app by default. To run Katalog, try one of these methods:

  1. Right-click the app → select "Open" (not double-click) → confirm in the dialog
  2. Or go to System Settings → Privacy & Security → scroll down and click "Open Anyway"
  3. Or run in Terminal: xattr -cr /path/to/Katalog.app then open normally. Add sudo in front if permission is denied.

Known limitation:

on Macs managed by an organization (MDM/corporate profile), these workarounds may be blocked by security policy. There is currently no solution for managed Macs — this would require signing the app with an Apple Developer certificate.

A legacy build (v2.5, pure Qt6, no KF6 dependencies) is also available with the same macOS requirements.
