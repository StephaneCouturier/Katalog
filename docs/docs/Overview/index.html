Overview

Files indexing & Storage devices manager​

Katalog is a powerful file catalog manager that helps you organize and find files.
It gives a full view of the files across multiple storage devices without needing them connected.
Katalog creates comprehensive indexes so you can search your entire file collection from one place, whether you're managing Internal and External Drives, USB sticks, Network storage, or storage Discs (blueray, DVDs, CDs).

  • Catalog everything: Create detailed indexes of files from any storage device
  • Search offline: Find files instantly without connecting or mounting the original device
  • Organize the collection: Manage multiple storage devices and their catalogs in a unified hierarchy

8 main tabs for 8 main features

  1. Create catalogs of files
  2. Search files across multiple storage devices without needing them connected
  3. Explore the catalogs' hierarchy and files
  4. Organize storage Devices and their catalogs in a unified hierarchy with virtual devices
  5. Get Statistics about your file collections & storage usage
  6. Personalize Tags and assigned them to directories for extra searching or statistics
  7. Compare BackUp catalogs to confirm the coverage of backed up files and folders between source and target devices
  8. Personalize your experience with your Settings such as language and theme



and a Selection panel to


  • Choose searching in Catalogs or directly in Connected drives
  • Set the device in the hierarchy to be used Search or Create or get Statistics or manage BackUp coverage

Key features​

Rich File Information​

  • File Type intelligence: Standard detection from extensions, and MIME type verification
  • Catalog options: Only include a type of files , and include/exclude directories or hidden files
  • Metadata extraction: Automatically extract metadata from images (dimensions, camera info), videos (duration, resolution), and audio files (artist, album, duration) or any other file type.
  • Folder Tag system: Organize and categorize folders with custom tags

Powerful Search & Discovery​

  • Advanced Search parameters: Find files by name, path, size, date, file type, and metadata
  • Smart Filtering: Use multiple criteria simultaneously to narrow down results quickly
  • Find Duplicates: Identify duplicate files across different storage devices
  • Find Differences: See differences between two storage locations or backup versions

Device & Catalog Management​

  • Device Organization: Organize storage devices in a hierarchical structure (Virtual > Storage > Catalogs)
  • Update: Keep catalogs current with manual updates or automatic updates
  • Import Support: Import catalogs from other tools like VVV

Analysis & Management​

  • File Explorer: Browse catalog contents as if the device were connected
  • Statistics: Track your file collections & storage usage
  • Backup Management: Map and compare source directories with their backups
  • Batch Operations: Export results and perform batch actions on files

Advanced Capabilities​

  • Command Line Interface: Automate catalog updates and searches via command line (Linux)
  • Database Flexibility: Choose between CSV files or SQLite database storage
