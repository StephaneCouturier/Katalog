Release 3.beta1

August 31, 2026 · 3 min read
Stephane Couturier
Developer of Katalog

Hello all,

It has now been 2 years since the very first tests of QML, Kirigami, on Linux & Windows, confirming the feasibility and next big step for Katalog user experience.
Katalog 3.0 release is near!

This is a message to call to anyone who would like to contribute and help to improve the quality before official Release. Feel free to post feedback here, or directly as issues.

✨ What is Katalog 3​

Katalog 3 is the new major version of Katalog, transitionning to a more modern User Interface. It relies on QtQuick (instead of QtWidgets) and Kirigami from KDE.

Katalog 2 will be maintained for some time to address major bugs & light feature changes. Katalog 2.13 will be released at the same time as Katalog 3.0 to maintain full db compatiblity.

This is enabled by having done a full split of UI and backend. The common use of /core (backend) means that Collections will remain compatible between both latest versions.

✨ Before testing​

  1. ⚠️ BACKUP YOUR COLLECTION(S) FIRST 💾 !

  2. CREATE A TEST COLLECTION IN KATALOG 2 BEFORE

  3. Info: to make it even safer, when opening Katalog 3 beta1 for the first time, it will NOT use the same settingsFile (.ini) and therefore it will NOT open your last Collection nor personnal settings.
    This is to protect even more your current collection and get your feedback on a fresh start as well.

  4. Important for macOS users: this version has NOT been tested on a macOS and may not start at all (previous feedback received on version 3.alpha2). Please report if it starts or not, this would be very useful.

✨ What to test​

  • Note: documentation updates are not available yet

  • New UI and global experience (starting from a blank Collection). Screenshots are very appreciated when describing an issue.

  • Conversion of a copy of a collection (low risk but important to secure) Once in Katalog 3, open a COPY of your main collection.
    ⚠️ Do not open files with Katalog 2.12 after using them in Katalog 2.13 or 3.0, some issues would appear.

  • Try out Katalog 2.13 beta1 on the same collection

  • Katalog 3 new features: see: Katalog 3 changes (it is not quite exhaustive but already a good list)
