Release 2.9

7. února 2026 · 2 min read
Stephane Couturier
Developer of Katalog

✨ Main improvements:

  • #664 CREATE/SEARCH: File Checksum SH256 for Duplicate/Difference Search It is now possible to compute and store files checksum in the catalogs. It is a much longer process than other indexing option as it reads ALL of the data to compute the checksums. Like file metadata, the option can be selected at catalog creation or changed later, and when interrupting the process, the calculated checksum are saved and the next update will resume for remaining files. The files checkum can be used as a duplicate search option or as a difference search option

Release 2.8

9. listopadu 2025 · 2 min read
Stephane Couturier
Developer of Katalog

✨ Main improvements:

  • #379 CREATE/ SEARCH: File Types management Instead of hard-coded and limited list, Katalog now uses a standard database, with more than 1200 known types, to determine the type from the extension and it can also verify the real mime type and report gaps. The definition of main types "Images, Audio, Video" is strictly related, only the type "Text" was customized to include types such as PDF. see Create#file-type-categories
